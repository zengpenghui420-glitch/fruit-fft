# 水果塑形测试 · 你是什么水果人格

测测日记 · 付费移动端 H5 娱乐测验。18 道原创 Likert 题，六维味道轮廓匹配 12 种水果人格。

## 在线地址

https://zengpenghui420-glitch.github.io/fruit-fft/

打开后应直接进入测验封面（`index.html`），而不是本说明页。

## 产品要点

| 项 | 说明 |
|---|---|
| 题目 | 18 题 · 五级自评（完全不像我 → 非常像我），一题一屏 |
| 维度 | 甜度外显 / 清酸锋利 / 汁感热情 / 果皮厚度 / 成串社交 / 后味层次（顺序 S-T-J-R-C-D） |
| 计分 | 每维 3 题，其中 1 题反向（`6−v`）；维分 `(mean−1)/4×100`。档位 0–33 低、34–66 中、67–100 高，只用于匹配 |
| 结果 | 主导水果人格 + 匹配度% + 次近水果 + 名为「水果塑形」的六维雷达 + 特征 / 他人视角 / 相处建议 |
| 类型 | 12 种原创水果人格，按六维 L/M/H 向量的曼哈顿距离匹配。水果没有高低贵贱 |
| 验证码 | `FF` + 4 位，字符表 `ABCDEFGHJKMNPQRSTUVWXYZ23456789`；每码 3 次 |
| 接口 | `https://snappy-tundra-7uesdvk.tmp.now` ，`POST /redeem`，JSON `{quiz:"fruit", code}`；**不接 Mantle** |
| 重新测试 | 清除会话解锁 → 再弹码 → redeem（扣 1 次） |
| 查看上次 | 只读本机 `fruit_last_result`，不请求 redeem、不扣次 |

## 免责声明

本测试为娱乐向自我观察，非正式心理测量或人格鉴定，不能替代专业评估。「水果人格」只是用果味比喻你近来待人处事的气质，不是对任何人的品级排序，也没有哪一种水果更高一等；结果会受当下心情与作答状态影响，图一乐、拿去分享都好，别把它当成性格判决书。

味道会随季节变化。今天测出来偏酸或偏甜，只说明此刻的口感，不定义你整个人。若某个比喻让你不舒服，丢掉它就好，你比任何水果标签都立体。

「FFT」只是本测验「水果塑形测试」的趣味缩写，不是心理测量学量表，也与任何第三方题库无关。

## 文件

- `index.html` — 单文件 H5（内联 CSS / JS），GitHub Pages 从仓库根目录提供
- `.nojekyll` — 让 Pages 按静态文件发布，不走 Jekyll
- `CODES.md` — 验证码格式与规则（无可卖码）
- `tools/mint.sh` — 只打印 vault 造码用法，不生成、不写入真码

## 本地预览

```bash
python3 -m http.server 8080
```

浏览器打开 http://127.0.0.1:8080/ 。未解锁时点「开始测试」会要求验证码，题目不会进入作答屏；「查看上次结果」只在本机有过结果时出现，且只读本地缓存。

## GitHub Pages

从 `main` 分支的根目录 `/` 发布。仓库需保留 `.nojekyll`，且根目录的 `index.html` 是测验页面。

## 码规则（不要把可卖码写进仓库）

- 前缀 `FF`，后接 4 位，字符表不含 I / L / O / 0 / 1
- Vault quiz key：`fruit`（发码池 `pools/fruit.txt`，由 vault 维护，不在本仓库）
- 造码只在 companion vault 上做，见 `tools/mint.sh` 与 `CODES.md`
- 本仓库不存放可卖验证码、ADMIN、PAT 或任何密钥
